Two panels show actual returned Pentakis cells for the same 1 km WGS84 buffer of all 1,482 Nose Hill Park boundary segments. Panel (a) contains 78 level 12 cells; panel (b) contains 941 level 14 cells. Blue triangles are returned cells and the black curve is the source boundary. This is distance to the boundary on both sides, not distance to a filled park polygon. EPSG:3776 is used only to display the already computed WGS84 result. Curved cell edges are sampled only for rendering. Neither the plotting projection nor the visual samples determine membership. The finer cells follow the requested region more closely. No unsampled cell subset is substituted for the result.
